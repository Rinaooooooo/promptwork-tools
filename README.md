# PromptWork Tools

**Free AI office tools that save you an hour a week.**

🌐 **Live site: [https://promptwork-tools.pages.dev/](https://promptwork-tools.pages.dev/)**

PromptWork Tools is a set of free, browser-based generators for everyday office writing. Every tool runs 100% in your browser — no sign-up, nothing you type is uploaded or stored — and each one produces a structured result plus a copy-ready AI prompt you can paste into ChatGPT or Claude.

## How it is built

- `build_site.py` generates the whole static site into `site/` (plain HTML/CSS/JS, no build step, no dependencies).
- Hosted on Cloudflare Pages. Everything is client-side: the generators assemble results locally in the browser and never send input anywhere.
